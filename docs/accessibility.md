# 접근성 점검 (KWCAG 2.2)

항목 번호는 비공식 정리본 기준입니다. axe 자동 검사와 아래 수동 점검을 함께 사용하며, 공식 인증을 받은 것은 아닙니다. 스크린 리더 실기 점검은 아직 하지 않았습니다.

| 항목                  | 대응                                                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5.1.1 대체 텍스트     | 첫 화면 평면도에 설명, 물건마다 이름·치수·위치를 담은 접근 가능한 이름. 카드 썸네일은 장식으로 숨김                                                              |
| 5.3.2 선형구조        | 물건 추가 → 배치도 → 속성·점검 순서가 화면과 DOM에서 같음                                                                                                        |
| 5.4.1 색 무관 인식    | 점검 상태는 아이콘과 `오류`·`주의`·`통과` 글자로 함께 표시, 선택은 모서리 표시 병행                                                                              |
| 5.4.3 명도 대비       | 글자에는 빨강 `#c62828`(종이 배경 약 5.1:1)을 쓰고 `#ff3e3e`는 글자 아닌 표시에만 사용                                                                           |
| 6.1.1 키보드          | 배치, 회전, 삭제, 화면 이동, 확대를 키보드로 수행                                                                                                                |
| 6.1.2 초점            | 물건의 초점 테두리, 추가·삭제 후 초점 이동, 초점 트랩 없음                                                                                                       |
| 6.1.3 조작 크기       | 작은 물건도 화면 기준 28px 이상의 대상 영역                                                                                                                      |
| 6.1.4 문자 단축키     | `R`은 물건에 초점이 있을 때만 동작                                                                                                                               |
| 6.2.2·6.3.1           | 자동으로 움직이거나 깜빡이는 콘텐츠 없음. 도면 연출은 스크롤을 따르며, `prefers-reduced-motion`이면 완성된 도면과 전체 단계를 바로 표시                          |
| 6.4.1 건너뛰기        | 페이지마다 바로가기 링크                                                                                                                                         |
| 6.4.2 제목            | 페이지별 `title`, 제목 계층                                                                                                                                      |
| 6.5.1 단일 포인터     | 끌기마다 숫자 입력, 회전 버튼, 화면 이동·확대 버튼 대안                                                                                                          |
| 6.5.2 포인터 취소     | 끌기 중 Esc와 `pointercancel`로 시작 상태 복원                                                                                                                   |
| 7.1.1 기본 언어       | `lang="ko"`, 영어 문구는 `lang="en"`                                                                                                                             |
| 7.2.2 찾기 쉬운 도움  | 편집 화면의 단축키 안내                                                                                                                                          |
| 7.3.1 오류 정정       | 범위 오류를 입력과 연결해 안내, 파일 오류는 이유 표시, 되돌리기 제공                                                                                             |
| 7.3.2 레이블          | 모든 입력에 레이블 연결                                                                                                                                          |
| 8.2.1 웹 애플리케이션 | 룰러와 X-ray 오버레이는 시각 표현이라 `aria-hidden`이고 같은 정보를 입력값, 점검 패널, `aria-live`로 제공. 오른쪽 스크롤 눈금은 기본 스크롤 수단을 대체하지 않음 |

해당 없음: 5.2.1 자막, 5.3.1 표, 5.4.2 자동 재생, 6.2.1 응답시간, 6.4.4 고정 참조 위치, 6.5.4 동작기반 작동, 7.3.3 인증, 7.3.4 반복 입력.
